# Product Catalog

A small React Native product catalog that lists, searches, and shows DummyJSON products.

## Stack

- Expo SDK 57 + React Native + TypeScript
- React Navigation (native stack)
- DummyJSON Products API (no API key)

## How to run

```bash
npm install
npm start
```

Then open the project in Expo Go, an Android/iOS simulator, or press `w` for web.

```bash
npm run web
npm test
```
